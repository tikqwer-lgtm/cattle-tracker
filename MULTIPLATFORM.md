# Мультиплатформенный запуск

## Веб (текущий режим)

Откройте `index.html` в браузере или разместите папку на любом веб-сервере. Для многопользовательского режима запустите бэкенд (см. ниже) и в приложении укажите адрес сервера: **Вход** → поле «Адрес сервера» → **Сохранить** (приложение перезагрузится в режиме API).

## Бэкенд API (многопользовательский режим)

```bash
cd server
npm install
npm start
```

Сервер: `http://localhost:3000`. В приложении откройте **Войти / Пользователи** (или экран входа), введите адрес сервера (например `http://localhost:3000` для локальной проверки) и нажмите **Сохранить**. При первом запуске зарегистрируйте пользователя через форму «Регистрация». Для чат-консультанта на сервере задайте переменную окружения `DEEPSEEK_API_KEY` (см. server/README.md).

## Десктоп (Electron)

**Исходный код веб-приложения** — в корне репозитория (`js/`, `css/`, `index.html`). Перед сборкой Electron копирует его в `electron/` скриптом `electron/copy-web.js` (в т.ч. папка `dist/` после `npm run build`). **Правки вносите только в корневые `js/` и `css/`**, не в `electron/js/` и `electron/css/` — они перезаписываются при сборке.

```bash
cd electron
npm install
npm start
```

Откроется окно с приложением. Для работы с API укажите адрес сервера в приложении: **Настройки → Войти / Пользователи** → поле «Адрес сервера» → **Сохранить**.

## Мобильные приложения (Capacitor)

Capacitor использует собранный каталог `dist/` (`webDir: "dist"` в [capacitor.config.json](capacitor.config.json)). Перед синхронизацией и запуском на устройстве обязательно соберите веб-приложение.

Из корня проекта:

```bash
npm install
npm run build
npx cap sync
npx cap run android
# или для iOS (только на Mac): npx cap run ios
```

Команды `cap` и `npm run apk` выполняйте **из корня репозитория** (где лежит `capacitor.config.json`), не из папки `android/`.

**Сборка APK с обновлением версии:** перед выкладкой на телефон можно поднять patch-версию в `package.json`, `versionCode` в Android и синхронизировать подписи:

```bash
npm run apk:release
```

Затем из папки `android`: `.\gradlew.bat assembleDebug` (Windows) — APK: `android/app/build/outputs/apk/debug/app-debug.apk`. Установка по USB: `adb install -r android/app/build/outputs/apk/debug/app-debug.apk`.

Отдельно только поднять версию без сборки: `npm run apk:bump` (скрипт `scripts/bump-version.js`).

Платформы Android и iOS уже добавлены (`android/`, `ios/`). Если добавляли проект с нуля: `npx cap add android` и/или `npx cap add ios`, затем `npx cap sync`.

**Требования для разработчика (сборка и запуск на устройстве):**

- **Android:** [Android Studio](https://developer.android.com/studio) и Android SDK; телефон с включённой отладкой по USB или эмулятор.
- **iOS:** Mac, [Xcode](https://developer.apple.com/xcode/); iPhone или симулятор iOS.

При первом запуске на физическом устройстве может понадобиться один раз открыть нативный проект в Android Studio / Xcode и настроить подписание (Signing). Для публикации в магазины соберите и подпишите приложение в Android Studio / Xcode.

**Подключение с телефона к серверу на ПК**

Телефон не может подключаться к `localhost` — для него это сам телефон. Чтобы приложение на телефоне работало с вашим сервером на компьютере:

1. **Сервер нужно запускать на ПК.** Пока сервер не запущен, телефон не сможет подключиться.
   - **Из корня проекта:** дважды запустите **Запустить-сервер.cmd** или в терминале: `npm run server`.
   - **Из папки server:** `npm start` или `npm run server`.
   Сервер слушает порт 3000. Чтобы он был **всегда в работе** (при каждой загрузке Windows), см. [server/Сервер-при-загрузке-Windows.md](server/Сервер-при-загрузке-Windows.md) (планировщик заданий или служба Windows).
2. **Узнайте IP-адрес ПК** в локальной сети (например, в PowerShell: `Get-NetIPAddress -AddressFamily IPv4`; или «Параметры Windows → Сеть и Интернет»). Обычно это адрес вида `192.168.x.x`.
3. **Телефон и ПК должны быть в одной Wi‑Fi сети.**
4. **В приложении на телефоне:** откройте меню → **Войти** (или **Настройки → Войти / Пользователи**), в поле **«Адрес сервера»** введите `http://IP_ВАШЕГО_ПК:3000` (без слэша в конце), например `http://192.168.1.148:3000`, нажмите **Сохранить**. Приложение перезагрузится и перейдёт в режим работы с API.
5. При первом подключении зарегистрируйте пользователя (кнопка «Регистрация») или войдите, если учётная запись уже есть на сервере.

**Почему на телефоне «нет баз», как на ПК**

Список баз на сервере пустой, пока кто-то не выгрузит базу на сервер. Сделайте так: на **ПК** откройте приложение (веб или десктоп), подключитесь к тому же серверу (Войти → адрес сервера → Сохранить), откройте **Синхронизация** и нажмите **Синхронизация** (или «Выгрузить текущую базу на сервер»). После этого на телефоне в разделе **Синхронизация** появится эта база — её можно открыть или скачать в текущий объект.
