# Визуальное оформление приложения на телефоне

## Текущее состояние

- **Прокрутка:** основной контент и списки используют `overflow: auto` или `overflow-y: auto`; в [css/responsive.css](css/responsive.css) на экранах ≤600px у `.view-entries-wrapper` задано `overflow-x: auto` и таблица имеет `min-width: 600px`.
- **Логотип:** в меню и печатной шапке используется [icons/icon.svg](icons/icon.svg); в [index.html](index.html) блок `.menu-branding` и `#print-header` ссылаются на него.
- **Масштабирование списков:** жестов зума нет; логика — [js/features/view-list.js](js/features/view-list.js), [js/features/lists.js](js/features/lists.js), плюс `#allInseminationsList`.
- **Кнопки:** стили в [css/components-buttons.css](css/components-buttons.css), [css/forms.css](css/forms.css), [css/responsive.css](css/responsive.css); меню — grid 2 колонки, подменю на ≤480px — одна колонка; формы и панели действий с разными отступами и размерами.

---

## 1. Только вертикальное движение окна (без горизонтальной прокрутки, кроме списков)

В [css/responsive.css](css/responsive.css) (например в `@media (max-width: 768px)`):

- Для `html` и `body`: `overflow-x: hidden`.
- Для основных контейнеров экранов (`.screen`, контент): `overflow-x: hidden; overflow-y: auto`.
- Исключения: `.view-entries-wrapper`, `.view-virtual-body`, `.list-table-wrap` — оставить `overflow-x: auto` для широких таблиц.
- Опционально: `touch-action: pan-y` на `body`.

---

## 2. Масштабирование списков пальцами (pinch-to-zoom)

- Утилита [js/utils/pinch-zoom.js](js/utils/pinch-zoom.js): по двум пальцам считать масштаб, применять `transform: scale(zoom)` к контенту списка (диапазон например 0.7–1.5).
- Подключить к контейнерам в view-list.js (виртуальный список), lists.js (УЗИ/осеменение), и к `#allInseminationsList`.

## 3. Логотип с картинки

- Разместить изображение логотипа (корова + «МОЛОЧНАЯ КОМПАНИЯ ГЕНЕТИКА») в [icons/](icons/) (например `logo-genetika.png`).
- В [index.html](index.html) заменить в `.menu-branding` и `#print-header` ссылку с `icons/icon.svg` на новый файл.
- В [css/layout.css](css/layout.css): для прямоугольного логотипа убрать или скорректировать `border-radius: 50%` у `.menu-branding-logo`, подправить размеры при необходимости.

## 4. Формат и расположение кнопок (лаконичный вид на телефоне)

**Цель:** единый, лаконичный вид кнопок на мобильных — без лишних отступов, с предсказуемым расположением и размером.

**Подход:**

- **Единые правила для мобильных** (в [css/responsive.css](css/responsive.css) или в [css/components-buttons.css](css/components-buttons.css) внутри `@media (max-width: 768px)` / `600px`):
  - Минимальная высота нажатия: оставить `min-height: 44px` для всех интерактивных кнопок.
  - Единый `gap` между кнопками: 8–12px в группах и панелях действий.
  - Компактные `padding`: например 10px 14px для обычных кнопок, 12px 16px для крупных пунктов меню.
  - Один стиль скругления: `var(--radius-md)` или `var(--radius-card)` везде; без лишних теней на мобильных для более чистого вида.

- **Главное меню** ([css/components-buttons.css](css/components-buttons.css)):
  - Сейчас: grid 2 колонки, `min-height: 88px`, `gap: 14px`. Для лаконичности: на узких экранах (например ≤480px) уменьшить `min-height` (например до 72–76px), `gap` до 10–12px, `padding` кнопок до 10px 12px.
  - Сохранить две колонки для быстрого доступа; при необходимости добавить медиа для очень узких (≤380px) с одной колонкой.

- **Подменю (menu-section-buttons)**:
  - Уже одна колонка на ≤480px. Задать единый `gap: 10px`, компактный вертикальный ритм; кнопки на всю ширину (уже через `1fr`).

- **Формы (.form-actions)** ([css/forms.css](css/forms.css)):
  - На телефоне: кнопки в одну строку с переносом при нехватке места (`flex-wrap: wrap`) с небольшим `gap` (8–10px) или в столбец (`flex-direction: column`) для очень узких экранов — чтобы блок выглядел аккуратно и не растягивался.

- **Панели действий** (bulk-actions-bar, списки, карточка коровы):
  - В [css/responsive.css](css/responsive.css) на ≤600px bulk-actions уже в колонку — сохранить; выровнять отступы с остальными экранами (единый `gap`, padding контейнера).
  - Кнопки в карточке коровы ([css/view-cow.css](css/view-cow.css)): на мобильных компактный ряд или столбец с единым отступом.

- **Итог:** один файл или один блок медиа-запросов для мобильных, где задаются: уменьшенные gap/padding для всех кнопочных зон, при необходимости `flex-direction: column` для form-actions на узких экранах, и чуть более компактные блоки главного меню — без изменения логики, только визуальная унификация и лаконичность.

## Порядок внедрения

1. CSS: вертикальная прокрутка и запрет горизонтальной вне списков.
2. Логотип: файл в `icons/`, правки index.html и layout.css.
3. Утилита pinch-zoom и подключение к спискам.
4. Формат и расположение кнопок: медиа-запросы и правки в components-buttons.css, forms.css, responsive.css.

В конце — сборка (`npm run build`) и при необходимости `npx cap sync` для проверки на устройстве.
