# План: настройка «Списка на УЗИ»

## Текущее состояние

- **Файл:** [js/features/lists.js](js/features/lists.js) — формирование списка и UI экрана «Список на УЗИ».
- Сейчас: два поля даты («С» / «По»), фильтр «Категория» (Все / Коровы / Телки), таблица без сортировки по клику и без полей «Осеменатор» и «Лактация».
- Логика УЗИ: УЗИ1 — попадание «дня 32» в диапазон дат и расчёт дней до `toDate`; УЗИ2 — `getDaysPregnant(entry) > 60` (относительно сегодня), без привязки к выбранной дате.

## 1. Одна дата вместо диапазона

- В форме УЗИ убрать поля «С» и «По», оставить **одно** поле даты, например `id="uziListDate"`, значение по умолчанию — сегодня.
- Сигнатуру и тело `getUziList` переписать под **одну дату** `date` (YYYY-MM-DD):
  - **УЗИ1:** статус содержит «Осемененная», есть последнее осеменение на или до `date`, и **на выбранную дату** дней от осеменения ≥ 32: `daysBetween(lastInsem, date) >= 32`.
  - **УЗИ2:** статус содержит «Стельная», `uziHistory.length === 1`, и **на выбранную дату** дней от осеменения ≥ 60: `daysBetween(lastInsem, date) >= 60` (не использовать `getDaysPregnant`, т.к. он считает до «сегодня»).
- Убрать использование `from`/`to` и проверку «firstDay32 в [from, to]»; оставить только проверки по одной дате и `daysBetween`.

## 2. Поля «Осеменатор» и «Лактация»

- В объект каждой строки списка (и УЗИ1, и УЗИ2) добавить:
  - `inseminator`: из `lastInsemRec.inseminator` или `entry.inseminator`, иначе `''` / `'—'`;
  - `lactation`: `entry.lactation` (число или строка), для отображения нормализовать пустые/нули в `'—'` при выводе.
- В таблицу добавить колонки **Осеменатор** и **Лактация** (логичный порядок: после «Попытка» или между «Группа» и «Дата осеменения» — на усмотрение, в плане — после «Попытка»).
- Обновить вызовы печати и экспорта в Excel: добавить ключи `inseminator`, `lactation` и заголовки «Осеменатор», «Лактация».

## 3. Сортировка по полям

- Заголовки таблицы сделать кликабельными (кнопки или `<th>` с `data-sort-key` и курсором).
- При клике по заголовку: сортировать `wrap._listData` по соответствующему полю (строка/число/дата), с переключением направления (asc/desc) при повторном клике по тому же полю; обновлять только tbody (перестраивать строки), не трогать разметку фильтров.
- Учесть типы: даты и числа — сравнение по значению, строки — по `localeCompare`; пустые значения в конце при asc.

## 4. Фильтр по лактации вместо «Категория»

- Убрать выпадающий список «Категория» (Коровы/Телки/Все).
- После расчёта списка по дате получить **уникальные значения лактации** из строк списка (по полю `lactation`), отсортировать и отобразить как набор **чекбоксов** с подписью по номеру лактации (например «1», «2», «3»).
- Две кнопки: **«Выделить все»** — отметить все чекбоксы лактаций; **«Убрать все»** — снять все галочки.
- Логика отображения строк:
  - Если **ни одна лактация не выбрана** (все галочки сняты) — показывать **пустой список** (0 записей).
  - Если выбрана хотя бы одна лактация — показывать только те строки, у которых `lactation` входит в выбранный набор (сравнение с учётом приведения типа, т.к. в данных может быть число или строка).
- Фильтр по лактации применять **после** получения списка от `getUziList(date)`: сначала полный список по дате, затем фильтрация по выбранным лактациям; при изменении даты список пересчитывается, уникальные лактации пересобираются, чекбоксы можно по умолчанию оставить «Выделить все» (все отмечены).

## 5. Структура данных и места изменений

- **getUziList(date, filterLactationSet)**  
  - Второй параметр опционален: если передан (массив или Set выбранных лактаций), отфильтровать результат по `lactation`; если массив пуст (все снято) — вернуть пустой массив.
- **renderUziListSubScreen**:  
  - Один `<input type="date" id="uziListDate">`.  
  - Блок с чекбоксами лактаций + «Выделить все» / «Убрать все».  
  - При «Обновить»: считать дату, вызвать `getUziList(date)` → полный список; собрать уникальные лактации из этого списка; отрисовать чекбоксы (если список пуст — показать сообщение «Нет записей», чекбоксов нет); считать выбранные лактации, вызвать фильтрацию (или передать выбранные в getUziList и фильтровать внутри). Проще: getUziList только по дате возвращает полный список; в refresh после getUziList собираем лактации, строим чекбоксы, читаем выбранные и фильтруем массив перед отрисовкой таблицы.  
  - Таблица: колонки с сортируемыми заголовками, данные включают `inseminator`, `lactation`; для печати/Excel — те же поля.

## 6. Файлы и дубликаты

- Вносить изменения в [js/features/lists.js](js/features/lists.js) (корень проекта). Сборка (vite) включает этот модуль в бандл; electron при сборке копирует `js/` из корня и использует бандл из `dist/` — отдельно правки в `electron/js/features/lists.js` не требуются, если не используется отдельная сборка electron без копирования из корня.

## 7. Краткая последовательность реализации

1. Переписать `getUziList(date)` под одну дату и добавить в каждую строку `inseminator`, `lactation`; при необходимости добавить параметр фильтра по лактациям или фильтровать снаружи.
2. В `renderUziListSubScreen`: один input даты; убрать «Категория»; добавить блок «Лактация» с чекбоксами + «Выделить все» / «Убрать все»; при пустом выборе лактаций показывать пустой список.
3. Добавить в таблицу колонки «Осеменатор» и «Лактация» и сортировку по клику на заголовок (включая новые поля).
4. Обновить печать и экспорт в Excel для списка УЗИ (поля и заголовки Осеменатор, Лактация).

После этого список на УЗИ будет с одной датой, полями Осеменатор и Лактация, сортировкой по всем колонкам и фильтром по лактации с «Выделить все» / «Убрать все» (при снятых всех галочках — пустой список).
