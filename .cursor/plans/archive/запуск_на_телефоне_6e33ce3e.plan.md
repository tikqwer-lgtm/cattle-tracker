# Запуск проекта на телефоне (Capacitor)

## Текущее состояние

- **Capacitor** уже в проекте: зависимости в [package.json](package.json) (`@capacitor/cli`, `@capacitor/core`, `@capacitor/android`, `@capacitor/ios`), скрипты `cap:sync`, `cap:android`, `cap:ios`.
- **Сборка веб-приложения**: Vite кладёт результат в `dist/` (index.html, app.js, css/, icons/, manifest.json, sw.js) — см. [vite.config.js](vite.config.js).
- **Проблемы**: в [capacitor.config.json](capacitor.config.json) указано `"webDir": "."` (корень проекта), тогда как для мобильных сборок должен использоваться собранный каталог `dist/`. Папок `android/` и `ios/` в репозитории нет — платформы ещё не добавлены.

## Что сделать

### 1. Привести Capacitor к использованию `dist/`

В [capacitor.config.json](capacitor.config.json) заменить `"webDir": "."` на `"webDir": "dist"`. Тогда при `cap sync` в нативное приложение будет копироваться только собранный вывод Vite, без лишних файлов и без расхождений с package.json (где уже указано `"webDir": "dist"` в секции `capacitor`).

### 2. Добавить платформы Android и iOS

Из корня проекта выполнить:

```bash
npx cap add android
npx cap add ios
```

Будут созданы каталоги `android/` и `ios/` с нативными проектами (их обычно добавляют в `.gitignore` или коммитят — на ваше усмотрение).

### 3. Сборка и синхронизация перед запуском на телефоне

Перед каждым запуском на устройстве/эмуляторе:

```bash
npm run build
npx cap sync
```

Либо одной цепочкой для Android: `npm run build && npm run cap:sync && npm run cap:android` (для iOS — `cap:ios` вместо `cap:android`).

### 4. Запуск на устройстве

- **Android**: установить [Android Studio](https://developer.android.com/studio) и SDK, включить «Отладка по USB» на телефоне и подключить по USB (или запустить эмулятор). Затем из корня: `npx cap run android` — откроется Android Studio или сразу устройство/эмулятор с приложением.
- **iOS**: только на Mac. Установить Xcode, подключить iPhone или запустить симулятор. Из корня: `npx cap run ios` — откроется Xcode/симулятор с приложением.

При первом запуске на физическом устройстве может понадобиться один раз открыть нативный проект в Android Studio / Xcode и настроить подписание (Signing) для устройства.

### 5. Документация

Обновить [MULTIPLATFORM.md](MULTIPLATFORM.md): явно указать, что перед `cap sync` нужен `npm run build`, и что в конфиге используется `webDir: "dist"`; при необходимости добавить краткий раздел про требования (Android Studio, Xcode, отладка по USB).

## Порядок действий (кратко)

1. Правка `capacitor.config.json`: `webDir` → `"dist"`.
2. `npm run build` (проверить, что `dist/` собирается).
3. `npx cap add android` и `npx cap add ios`.
4. `npx cap sync`.
5. Запуск: `npx cap run android` и/или `npx cap run ios` (при установленных Android Studio / Xcode и подключённом устройстве или эмуляторе).
6. Обновить MULTIPLATFORM.md.

## Зависимости на окружении


| Платформа | Нужно для запуска на устройстве                                                |
| --------- | ------------------------------------------------------------------------------ |
| Android   | Android Studio, Android SDK; телефон с включённой отладкой по USB или эмулятор |
| iOS       | Mac, Xcode; iPhone или симулятор iOS                                           |


После этих шагов проект будет запускаться на телефоне как нативное приложение с тем же веб-интерфейсом, что и в браузере/десктопе.
