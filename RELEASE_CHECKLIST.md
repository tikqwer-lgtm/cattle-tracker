# Чек-лист перед релизом

Перед каждым релизом рекомендуется проверить ключевые сценарии.

**Автоматически (локальный режим, Playwright):**
- `npm run build`
- `npx playwright install chromium` (один раз)
- `npx playwright test e2e/release-checklist.spec.js e2e/roles-capabilities.spec.js --project=chromium`

**Вручную на проде:** вход по API, синхронизация, CRUD с реальной базой, мобильный APK, чат с `DEEPSEEK_API_KEY` на сервере.

## Ролевая модель релиза (mobile-first)

- `Lite`: карточки/списки, стойломеста, инвентаризация, ввод действий.
- `Medium`: всё из Lite + уведомления и аналитика.
- `Pro`: всё из Medium + настройки карточки хозяйства и мульти-база.
- `Admin`: всё из Pro + управление пользователями/ролями и release-контролы.

Проверка ролей автоматизирована тестом `e2e/roles-capabilities.spec.js`.
