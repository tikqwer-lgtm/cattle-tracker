# Чек-лист перед релизом

Перед каждым релизом рекомендуется проверить ключевые сценарии.

**Автоматически (локальный режим, Playwright):** `npm run build` затем `npx playwright install chromium` (один раз), `npm run e2e` — файл `e2e/release-checklist.spec.js` и `e2e/smoke.spec.js`.

**Вручную на проде:** вход по API, синхронизация, CRUD с реальной базой, мобильный APK, чат с `DEEPSEEK_API_KEY` на сервере.

## Вход и выход

- [x] Открывается экран входа (логин, пароль, кнопки «Войти», «Регистрация», «Без авторизации»). — *e2e*
- [x] Вход по логину и паролю (локально или с сервером) переводит на главное меню. — *локально: e2e «без пароля»; API: вручную*
- [x] Кнопка «Выйти» на главном экране выполняет выход и возвращает на экран входа. — *e2e*
- [x] После выхода фокус попадает в поле пароля (или логина). — *e2e, исправлен переход на `auth`*

## Главное меню и навигация

- [x] Все группы меню открываются: «Работа с данными», «Действия», «Аналитика», «Уведомления и планы», «Настройки». — *e2e*
- [x] В подменю кнопки ведут на соответствующие экраны (добавить животное, список, осеменение, отёл, УЗИ, аналитика, протоколы и т.д.). — *e2e: список, протоколы, чат*
- [ ] Переключатель объектов (баз) отображается и работает: выбор базы, «Изменить», «Удалить», «+ Добавить объект». — *вручную / с API*

## Данные

- [x] «Список всех животных» показывает записи (при наличии данных; при 0 записей — сообщение «Нет записей»). — *e2e (пустая база)*
- [ ] «Все осеменения» показывает данные об осеменениях (при наличии). — *вручную*
- [x] Информационное табло на главном экране (всего коров, стельных, в сухостое и т.д.) совпадает с количеством записей в списке. — *e2e при 0 записей*
- [ ] Добавление новой записи (корова) сохраняется и отображается в списке. — *вручную*
- [ ] Редактирование записи сохраняется. — *вручную*
- [ ] Удаление записи работает. — *вручную*

## Протоколы и настройки

- [x] Экран «Настройки — Протоколы синхронизации» открывается и показывает список протоколов и форму добавления/редактирования. — *e2e: переход*
- [ ] Добавление, редактирование и удаление протокола работают (локально или с сервером при включённом API). — *вручную*

## Синхронизация с сервером

- [ ] При включённом адресе сервера данные загружаются с API. — *вручную*
- [ ] Переключение базы (объекта) подгружает записи и протоколы для выбранной базы. — *вручную*
- [ ] Экспорт/импорт базы (если реализован в UI) включает протоколы. — *вручную*

## Экспорт и импорт

- [x] Экспорт в Excel (или выгрузка списка) работает. — *XLSX в бандле; e2e: наличие window.XLSX; выгрузку — вручную*
- [ ] Импорт из файла (CSV/Excel) при необходимости работает. — *вручную*

## Чат-консультант

- [x] Панель открывается из «Настройки → Чат-консультант» (и ПКМ «Вызвать консультанта»). — *e2e*
- [ ] Ответы приходят с сервера при `DEEPSEEK_API_KEY` (или Ollama) и указанном адресе API. — *вручную*

## Десктоп (Electron)

- [ ] Приложение запускается через `npm run electron` (или установленный exe). — *вручную*
- [ ] После сборки `npm run electron:dist` установщик из `electron/dist/` устанавливается и запускается без ошибок. — *сборка: `npm run installer`*
