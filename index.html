Как импортировать данные

Полный импорт — один файл CSV/XLSX со всеми столбцами: в окне сопоставления укажите столбец с номером животного и замапьте остальные поля.

Поэтапный импорт — сначала файл только с номерами (остальные столбцы «Не импортировать»), затем отдельные файлы с группами, отёлами, осеменениями, УЗИ. Повторный импорт дополняет данные по номеру, пустые ячейки не затирают уже загруженное.

Selex (2 файла) — 1) текущее стадо (карточки); 2) import_selex_events с столбцом «Тип события» (Осеменение / Отёл) — достраивает историю лактаций и журнал. Сначала файл 1, затем файл 2. «Автораспределение» по заголовкам.

Несколько строк с одним номером — несколько осеменений. Шаблон заголовков — кнопка «Шаблон импорта».

Пользователи

Заявки на доступ

Заявки «Забыл пароль» и «Запросить логин». Смените пароль пользователя выше, затем отметьте заявку выполненной.

Подключение к объектам

Выберите пользователя и отметьте объекты, к которым у него есть доступ. Администраторам назначать объекты не нужно.

Права пользователя

Выберите человека и включите или отключите функции. Пока переключатели не сохранены, действуют права его роли. Администратор всегда имеет полный доступ.

              Протоколы синхронизации

              Справка

              Журнал событий основного процесса и страницы при открытии и закрытии консоли разработчика. Нужен для поиска остаточных эффектов после закрытия DevTools. При зависании ввода в десктопе используйте кнопку «Обновить» в шапке.

              Синхронизация

              Логин и пароль хранятся на выбранном сервере. Укажите URL API (с http:// или https://), где у вас есть аккаунт. Пустое поле — берётся последний успешный адрес или адрес по умолчанию из сборки.

              Адрес сервера API

              Доступно администратору. Укажите новый URL, если сервер переехал (с протоколом http или https). После применения сессия сбросится — войдите снова.
