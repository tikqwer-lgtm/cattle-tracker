# Запуск сервера при загрузке Windows (сервер всегда в работе)

Чтобы сервер «Учёт коров» запускался автоматически при включении ПК и работал в фоне (как постоянно включённый сервис), можно использовать один из способов ниже.

## Способ 1: Планировщик заданий Windows

1. Откройте **Планировщик заданий** (Win + R → `taskschd.msc` → Enter).
2. **Создать задачу** (не «Создать простую задачу»).
3. Вкладка **Общие**: имя, например «Cattle Tracker Server», включите «Выполнять с наивысшими правами» при необходимости.
4. Вкладка **Триггеры** → **Создать**: «При входе в систему» (или «При запуске компьютера»), ОК.
5. Вкладка **Действия** → **Создать**:
   - **Программа:** полный путь к `node.exe` (например `C:\Program Files\nodejs\node.exe`).
   - **Аргументы:** полный путь к `server.js`, например `E:\VScode\cattle-tracker\server\server.js`.
   - **Рабочая папка:** `E:\VScode\cattle-tracker\server` (замените на свой путь).
6. ОК, введите пароль учётной записи при запросе.

После перезагрузки ПК сервер будет стартовать автоматически. Проверка: откройте в браузере `http://localhost:3000/api/health`.

## Способ 2: Ярлык в папке «Автозагрузка»

1. Создайте ярлык для файла **Запустить-сервер.cmd** из корня проекта (ПКМ по файлу → Создать ярлык).
2. Скопируйте ярлык в папку автозагрузки: Win + R → `shell:startup` → Enter, вставьте ярлык туда.

При каждом входе в Windows будет открываться окно с сервером (его можно свернуть). Чтобы не было окна, используйте способ 1 или 3.

## Способ 3: Сервер как служба Windows (NSSM)

[NSSM](https://nssm.cc/) — утилита, которая превращает любую программу в службу Windows (работает в фоне, перезапуск при сбое).

1. Скачайте NSSM с https://nssm.cc/download и распакуйте.
2. Откройте командную строку **от имени администратора**.
3. Установите службу (пути замените на свои):

```bat
nssm install CattleTrackerServer "C:\Program Files\nodejs\node.exe" "E:\VScode\cattle-tracker\server\server.js"
nssm set CattleTrackerServer AppDirectory "E:\VScode\cattle-tracker\server"
nssm start CattleTrackerServer
```

4. Служба будет запускаться при загрузке Windows. Управление: «Службы» (services.msc) → CattleTrackerServer, или `nssm stop/start CattleTrackerServer`.

---

Для доступа к серверу **из интернета** круглосуточно (как «Brainy Cepheus») нужен не только автозапуск на ПК, но и постоянный хостинг: VPS или облако (см. [DEPLOY_ALTERNATIVES.md](DEPLOY_ALTERNATIVES.md)) — тогда сервер работает 24/7 независимо от вашего ПК.
