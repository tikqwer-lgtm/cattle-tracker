# Сервисная версия — опросник функций

Согласованный состав версии **сотрудника сервисного отдела** (`service`).
Клиент = объект / хозяйство. Роли в БД не меняются: `admin` | `inseminator` | `service`.

Обозначения: **нужно** / **нужно, переработать** / **не нужно** / **нет в продукте**.

## Главное меню

- [x] Переключатель объектов (хозяйств клиента) — **нужно**
- [x] Карточка хозяйства — **нужно**
- [x] Работа со стадом — **нужно** (дашборд специалиста: осеменения, стельные, сомнительные УЗИ1, погрешность УЗИ)
- [ ] Администрирование / создание баз — **не нужно** (только admin)

## Карточка хозяйства

- [x] Адреса — **нужно** (просмотр; правка — admin)
- [x] Специалисты / контакты — **нужно** (просмотр + звонок / MAX)
- [x] Цели — **нужно** (просмотр)
- [x] Лента событий хозяйства — **нужно** + запись для сервиса
- [x] Показатели / динамика / быки — **нужно** (просмотр)
- [x] Печать A4 — **нужно**
- [ ] Импорт DC305 / Afifarm / Uniform — **не нужно**

## Работа со стадом — данные

- [x] Список всех животных — **нужно**
- [x] Карточка животного — **нужно**
- [x] Все осеменения — **нужно**
- [x] Список событий — **нужно, переработать** (фильтр «мои работы» — этап 2)
- [x] Списки: УЗИ / Осеменение / Задачи на дату — **нужно**
- [ ] Список отёлов — **не нужно** как основной сценарий сервиса
- [ ] Добавить животное — **не нужно**
- [x] Схема стойломест — **нужно** только просмотр
- [ ] Инвентаризация — **не нужно**

## Работа со стадом — действия

- [x] Ввести осеменение — **нужно**
- [x] УЗИ — **нужно**
- [x] На протокол — **нужно** (временный путь для уколов)
- [ ] Запуск / Отел / Аборт — **не нужно**
- [ ] Лечение — **нет в продукте** (этап 2)
- [ ] Уколы как отдельное событие — **нет в продукте** (этап 2)

## Аналитика и прочее

- [ ] Аналитика / воспроизводство / интервальный анализ — **не нужно**
- [x] Уведомления — **нужно**
- [ ] Настройки хозяйства / протоколы (редактирование) — **не нужно**
- [x] Синхронизация — **нужно**
- [x] Чат-консультант — **нужно**
- [ ] Excel, пользователи, APK, Bitrix — **не нужно**

- Фильтр журнала «мои работы / работы сервиса на этом хозяйстве»
